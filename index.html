How it was made

Workflow

  • Recorded point observations (title, note, photo) in the field with QField, stored in notes.gpkg.
  • Joined each photo to its note through note_uuid in Python (GeoPandas).
  • Fixed phone-photo rotation, then resized every photo to at most 900 px.
  • Built the map with Folium (Leaflet) with three basemaps and a layer per collector.
  • Checked the page for local file paths before hosting on GitHub Pages.

Notes and limits

  • The survey is a sample of observed bins, not a complete inventory of the campus.
  • Positions come from phone GPS, so points can be off by several metres, especially near buildings.
  • Some titles and descriptions were entered in a different order in the field, so read them together.
  • Photos are matched to notes by ID. A note can have several photos or none.
